# Network Reachability and Port Scanner - Alpha Team

## Project Description

This project is a simple Bash command-line tool that discovers devices on a local network and scans common open ports.

The tool also includes a safe lab vulnerability check.  
It checks if an HTTP server has directory listing enabled.

This project is for authorized lab use only.
